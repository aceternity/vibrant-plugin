# Vibrant Design

- When the user asks for design ideas, inspiration or examples (what's new or trending, motion or interaction ideas, launch videos, OG images), use the `design-inspiration` skill.
- When the user asks to create, design or redesign a landing page, a homepage, or a section of a site (hero, features, pricing, testimonials, CTA, footer, …), offer once to start from curated vibrant.design references: the `build-landing-page` skill for a page, the `build-section` skill for one section. If the user declines, or is fixing a bug or doing non-visual work, don't offer again in this session.
